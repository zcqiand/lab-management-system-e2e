## 1. 需求描述

**我的理解**：lab 会话有两处与 saas 本质不同：登录靠 SSO orchestrator（无密码表单，
会话建立走 API 登录 + storage 预置）；切换租户无前端 UI（单租户换发语义）→ 不移植 saas
切换用例。本用例断言预置后业务页可达、登出清三端 storage key 并落回 /login。
